# AGENTS.md

Rules for any AI agent are the same as in [CLAUDE.md](CLAUDE.md).

In short: the lesson library is available through the `lecture-studio` MCP server (`.mcp.json`, `mcp_server.py`).
For questions about lessons, lectures or notes, start with `lecture_list_lessons` / `lecture_get_lesson_material`.
All timecodes are `[MM:SS]` on the clean timeline (they match clean_video.mp4 and clean_speech.mp3).
